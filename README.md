# Projet Python Data Science

## Étude du pouvoir prédictif du vent sur les traumatismes et le crime en France 

Projet de Matthieu Bonnet et de Jade Valade, Ensae 2026

### Motivation du projet

« Quand l’autan souffle, les fous d’Albi dansent », selon un dicton occitan (source : Sciences&Vie). Si aucune étude n'a montré l'effet causal du vent sur la folie, certains le suspectent. Nous n'avons pas de prétention de démontrer les effets psychiques de vents forts, mais nous nous intéressons à des effets potentiels du vent sur des accès de violence et des accidents.

### Navigation dans le git
